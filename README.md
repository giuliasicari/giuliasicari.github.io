# giuliasicari.github.io
Portfolio di Giulia Sicari – Art Director

Sito statico in HTML, CSS e JavaScript, pubblicato con GitHub Pages su https://giuliasicari.github.io.
Anteprima locale: `python3 -m http.server` nella cartella, poi apri http://localhost:8000.

Le immagini di ogni progetto sono in `images/<progetto>/` (`cover.jpg`, `01.jpg` … `04.jpg`):
per sostituire un segnaposto basta sovrascrivere il file con lo stesso nome.
Regole di stile e struttura in [CLAUDE.md](CLAUDE.md).
